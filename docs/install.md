# 설치·갱신·복구

대상은 PS3 일본판 **BLJM61084**, 기준 버전은 **v20260910b**입니다. 다른 리전·다른 파일 해시의 게임은 지원하지 않습니다. Windows와 .NET Framework 4.x가 필요합니다.

## 1. 준비와 다운로드

1. RPCS3를 완전히 종료합니다. ISO를 마운트했다면 해제합니다.
2. 직접 준비한 복호화 ISO 또는 폴더형 게임을 확인합니다. 암호화 ISO에는 적용하지 않습니다.
3. [WO3U_KR_v20260910b.zip](https://github.com/kimjh-eclipse/musou-orochi-2-ultimate-kor/releases/download/v20260910b/WO3U_KR_v20260910b.zip)을 내려받아 압축을 풉니다.
4. 게임 원본과 세이브의 별도 보관을 권장합니다. 패처의 구간 백업은 게임 전체 백업이 아닙니다.

배포 ZIP에는 `WO3U_ISO_QuickPatch.exe`, `README_사용법.txt`, `SHA256SUMS.txt`가 들어 있습니다. 패치 데이터는 EXE에 내장되어 있습니다. **릴리즈 ZIP을 사용하세요. 저장소 루트의 구형 배포 파일은 정리했습니다.**

```powershell
Get-FileHash .\WO3U_KR_v20260910b.zip -Algorithm SHA256
```

예상 값은 [전체 해시 목록](hashes.md)을 참고하세요. 다운로드 해시가 다르면 실행하지 말고 다시 받습니다.

## 2. 적용 대상 선택

| 실행 방식 | 패처에 지정할 대상 | 변경 파일 |
|---|---|---|
| ISO | 실제 사용하는 복호화 ISO | ISO 내부의 아래 5파일 |
| 폴더 | RPCS3 루트, 게임 루트, `PS3_GAME` 또는 `USRDIR` | 같은 5파일을 제자리 수정 |

```text
PS3_GAME/
  PARAM.SFO
  ICON0.PNG
  USRDIR/
    EBOOT.BIN
    LINKDATA.IDX
    LINKDATA.BIN
```

ISO를 실행하면서 별도의 추출 폴더에만 패치하면 실행 결과에는 반영되지 않습니다. 패처 로그의 대상 경로를 확인하세요. ISO 파일 전체 크기와 각 게임 파일 길이는 바뀌지 않습니다.

## 3. 처음 적용

1. 패처를 열고 **A. 복호화 ISO 파일** 또는 **B. RPCS3 / 폴더형 게임** 대상을 지정합니다.
2. 자동으로 채워진 백업 경로를 확인합니다. ISO는 기본적으로 `<ISO 경로>.wo3u-backup`, 폴더는 게임 폴더 밖의 백업을 사용합니다.
3. **상태 검사**를 실행해 원본 상태인지 확인합니다. 처음에는 약 9 GB의 게임 데이터를 읽으므로 시간이 걸릴 수 있습니다.
4. 주의사항을 확인하고 해당 대상의 한국어 패치 적용 버튼을 누릅니다.
5. 로그에서 **적용 후 5파일 전체 해시 검증 성공**을 확인합니다. 단순히 진행률이 끝난 것만으로 성공으로 판단하지 않습니다.

이미 최신 패치 상태라면 다시 쓰지 않습니다. 세이브·영상·음성·RPCS3 설정·캐시는 패처의 수정 대상이 아닙니다.

## 4. 구버전에서 갱신

새 패처에 **이전 패치 때 생성한 `.wo3u-backup`**을 지정합니다. 구버전 데이터를 백업으로 원본 복구하고, 원본 검증을 통과한 다음 새 패치를 적용하는 방식입니다. 이전 백업을 새 변경 구간 기준으로 갱신하므로 중요한 백업은 별도 복사해 보관하는 것이 좋습니다.

v20260910b는 이전 폴더형 3파일·4파일 백업을 읽을 수 있습니다. 다만 그 백업에 없는 `PARAM.SFO`나 `ICON0.PNG`가 이미 다른 내용으로 수정되어 있으면 안전하게 중단합니다. 이를 우회하려고 해시나 파일 길이를 임의로 맞추지 마세요.

백업이 없거나 다른 게임 복사본의 백업만 있다면 중단하고 원본을 다시 준비합니다. ISO용 백업과 폴더용 백업은 서로 바꿔 쓸 수 없습니다.

## 5. 명령줄 사용

아래 경로는 예시입니다. 실제 경로로 바꿔 사용하세요. `--yes`는 확인을 생략하며, `--no-pause`는 종료 때 Enter를 기다리지 않게 합니다.

```powershell
.\WO3U_ISO_QuickPatch.exe --iso "D:\Games\WO3U.iso" --verify-only
.\WO3U_ISO_QuickPatch.exe --iso "D:\Games\WO3U.iso" --yes
.\WO3U_ISO_QuickPatch.exe --folder "D:\RPCS3\dev_hdd0\disc\BLJM61084" --verify-only
.\WO3U_ISO_QuickPatch.exe --folder "D:\RPCS3\dev_hdd0\disc\BLJM61084" --backup "D:\Backups\BLJM61084.wo3u-backup" --yes
.\WO3U_ISO_QuickPatch.exe --iso "D:\Games\WO3U.iso" --restore --backup "D:\Games\WO3U.iso.wo3u-backup"
```

`--iso`와 `--folder`는 동시에 지정하지 않습니다. 자동화에서는 종료 코드와 최종 검증 로그를 함께 확인하세요.

## 6. 검증과 게임 실행

백업 배치가 현재 패치와 정확히 맞으면 상태 검사는 변경 구간만 비교하는 빠른 경로를 사용할 수 있습니다. **이 결과는 파일 전체 해시 검사와 다릅니다.** 실제 쓰기 직후에는 5파일 전체 해시를 검사합니다. 별도 전체 검증이 필요하면 폴더형 파일을 [해시 목록](hashes.md)과 직접 비교할 수 있습니다. ISO는 논리 파일을 추출하거나 extent를 따라 읽어야 하며, ISO 전체 해시와 게임 내부 파일 해시를 혼동하지 마세요.

패치 후에는 새로 부팅하고 게임 내부 세이브를 불러옵니다. 패치 전 Save State는 예전 폰트·문자열 메모리를 되살릴 수 있으므로 사용하지 않습니다.

목록 제목이나 아이콘이 옛 상태이면 먼저 실제 실행 경로와 5파일 적용 여부를 확인하고 RPCS3를 다시 시작하세요. 사용자 지정 제목이 있는지도 확인합니다. 세이브 삭제, 전체 캐시 삭제, 게임 삭제·재등록을 첫 해결책으로 요구하지 않습니다.

## 7. 복구

패처의 원본 복구 버튼 또는 `--restore`에 해당 대상의 백업을 지정합니다. 백업 무결성·대상 크기·구간을 검사한 뒤 원본 구간을 되쓰고 전체 해시를 확인합니다. 복구 후에도 백업은 남습니다.

실패·전원 중단이 발생했다면 대상과 백업을 보존하고 로그를 확인하세요. 백업은 변경 구간만 포함하므로 패치와 무관한 영역의 손상을 복구하지 못합니다. [복구 설계와 한계](patcher.md)를 참고하세요.
