# 빌드·검증·조사 범위

번역 파일을 만들었다는 것, 게임 데이터에 들어갔다는 것, 실제 화면에서 정상이라는 것은 서로 다른 완료 조건입니다. 이 문서는 그 증거 수준을 분리합니다.

## 빌드 절차와 산출물

| 단계 | 작업 | 통과 조건·증거 |
|---|---|---|
| 원본 고정 | 대상 리전·길이·해시 확인 | 원본 해시 목록, 변경 불가 기준본 |
| 추출 | IDX/BIN 파싱·압축 해제 | 추출 항목 ID와 payload 해시 |
| 조사 | LX 레코드·G1T 이미지 분류 | 원문, raw bytes, 레코드 키, 이미지 좌표 |
| 번역 | 문구·용어·제어 토큰 정리 | 번역 명세, 토큰 수·순서 일치 |
| 인코딩 | 고정 매핑으로 바이트 생성 | 누락 문자·중복 코드·이름 경계 검사 |
| 이미지 | 글리프·메뉴 영역 교체 | 허용 영역 밖 바이트·픽셀 동일 |
| 재구성 | 풀 재배치·재압축·삽입 | 길이·포인터·슬롯 용량, 재추출 일치 |
| 패키징 | 원본과 완성본 차이 팩 생성 | 파일별 원본/대상 해시, 구간 검증 |
| 적용 | ISO/폴더 패치·복구·갱신 | 독립 readback, 전체 파일 해시 |
| 화면 | 새 부팅 후 실제 메뉴·전투 확인 | 경로·상태별 캡처와 재현 기록 |

작업 중인 파일과 이미 검증한 빌드를 섞지 않도록 버전별 산출물을 분리합니다. 다음 버전을 만들 때는 앞 버전의 검증 결과를 그대로 재사용하지 않고 변경 범위와 보존 범위를 다시 비교합니다.

## 임무가 31개라는 수치의 의미

“던전 임무 31개”는 **게임 전체 임무가 31개라는 뜻이 아닙니다.** 당시 조사한 특정 던전 힌트 테이블은 100슬롯이며, 사용 슬롯 31개·예약 슬롯 69개였습니다. 31개 슬롯 안에는 중복 문구가 있어 고유 텍스트는 9개였습니다. 대응 분류 테이블도 사용 31·예약 69 구조였습니다.

이후 임무 관련 조사 범위를 선녀 의뢰·전장 설명·혼합 스테이지 문자열로 확대했습니다. 선녀 의뢰는 제목 80·목표 80의 대상 행을 확인했으며 각 계열에 예약 20개가 있었습니다. 슬롯 수, 고유 문구 수, 사용처 수, 게임에 등장하는 임무 수를 서로 바꿔 쓰면 안 됩니다.

## 교차 조사와 번역 보완

후속 조사에서는 LX 카탈로그 134,522레코드의 키워드 조사와 혼합 스테이지 계열 75,278레코드의 별도 검사를 수행했습니다. 두 조사 집합은 독립적인 전체 게임 개수나 단순 합산할 수 있는 수치가 아닙니다.

선정된 조사 범위는 483리소스·77,244사용처로 집계됐고, 한국어 또는 일본어가 아닌 항목 76,651개와 예약 항목 593개로 분류했습니다. 이 중 스테이지 계열 75,278개는 한국어 또는 일본어가 아닌 항목 74,863개와 예약 항목 415개입니다. 전체 카탈로그와 선정 범위, 하위 집합의 수치를 구분해서 읽어야 합니다.

최종 보완된 잔여 마스터 문구 117개는 전장 제목 35, 전장 설명 44, 갤러리 음성 표제 33, 기타 UI 5개입니다. 조사 범위의 잔여 일본어 검사 결과가 0이어도 미해석 포맷·미점검 이미지·키워드 밖 문자열의 완역을 증명하지는 않습니다.

다른 계열에는 소재 이름 295·설명 295, BGM 165, 무기 속성 이미지 58개 등의 일괄 보완이 포함됩니다. 이 수치는 해당 작업의 대상 수이며 게임 전체 항목 수라고 일반화하지 않습니다.

## v20260910b 검증 상태

| 대상 | 확인된 내용 | 남은 확인 |
|---|---|---|
| 번역 3파일 | v20260906b의 EBOOT·IDX·BIN과 동일한 목표 해시 | 모든 화면의 완역·잘림 검증 |
| SFO | TITLE·길이·기타 바이트 보존, 설치 ISO에서 재독출 | 최신 실행 화면의 제목 표시 |
| ICON0 | 320×176·80,484바이트·CRC·디코딩, ISO 재독출 | 최신 게임 목록의 실제 아이콘 표시 |
| 패처 | 적용·복구·구버전 백업 처리 테스트, 설치 대상 검증 | 모든 저장장치·모든 환경의 보증은 아님 |
| RPCS3 | 이전 번역판의 부팅 확인 이력 | 최신 메타데이터·추가 화면 전체 재확인 |

설치 ISO의 5파일 최종 검증과 SFO·ICON0 독립 readback을 확인했습니다. 이것을 화면 캡처 검증 완료라고 표현하지 않습니다. 실기 CFW PS3는 미검증입니다.

## 회귀 테스트의 핵심

- 원본에 적용 → 5파일 목표 해시 일치.
- 복구 → 5파일 원본 해시 일치.
- 같은 버전 재적용 → 불필요한 쓰기 없음.
- 이전 번역판 + 그 백업 → 원본 복구 후 최신판 적용.
- 이전 백업에 없는 SFO/ICON0가 다른 경우 → 쓰기 전 거부.
- 잘못된 크기·다른 리전·손상된 백업·겹치는 구간 → 거부.
- ISO extent 경계를 넘는 구간 → 나누어 기록한 결과 일치.
- 문자열 포인터·제어 코드·폰트 매핑·허용 이미지 영역 → 각각 독립 검사.

이름은 머리 위 표시와 대화창, 메뉴는 비선택과 선택 확대, 팝업은 짧은 문장과 긴 문장을 따로 확인합니다. Save State 대신 새 부팅으로 테스트해야 패치 전 메모리가 섞이지 않습니다.

## 공개 소스 범위와 재현 조건

현재 저장소의 [tools 안내](https://github.com/kimjh-eclipse/musou-orochi-2-ultimate-kor/blob/main/tools/README.md)와 `tools/iso_quickpatch/`에는 이전 3파일 패처·팩 생성·검증 코드가 있습니다. **최신 5파일 소스 및 번역 명세·매핑·전체 이미지 빌더가 모두 공개된 완전 재현 저장소는 아닙니다.** 루트의 이전 EXE·사용법·해시 파일은 정리했으며, 최신 배포물은 Releases에서 제공합니다.

최신 빌드를 완전히 재현하려면 정확한 원본 해시의 게임 데이터, 버전 고정 번역 명세, 고정 글리프 매핑, 이미지 교체 명세와 글꼴, 빌더 의존성, 5파일 패처 소스, 최종 검증 명세가 함께 필요합니다. 원본 게임 데이터는 배포 대상이 아닙니다.

이 문서의 포맷 설명은 실제 개발 구현을 검토한 결과지만, 문서만으로 원본 없이 최신 배포물을 재생성할 수 있다고 약속하지 않습니다. 공개되어 있지 않은 파일 이름을 내려받을 수 있는 링크처럼 표시하지도 않습니다.

## 다른 플랫폼으로의 이식

이 배포 패치는 PS3 일본판 전용입니다. 기존 번역문·용어집·이미지 제작물을 다른 플랫폼 작업의 입력으로 재사용할 가능성은 있지만, PC판의 문자열 대응·인코딩·폰트·아카이브·추가 콘텐츠를 별도로 조사해야 합니다. PS3의 바이트 오프셋, EBOOT, SFO, ISO 패처를 PC 게임에 그대로 적용할 수는 없습니다. 현재 문서는 PC판 호환이나 이식 완료를 주장하지 않습니다.
