## 직접 계산하기

아래는 현재 디렉터리가 `PS3_GAME`인 폴더형 게임의 예입니다.

```powershell
Get-FileHash .\USRDIR\EBOOT.BIN -Algorithm SHA256
Get-FileHash .\USRDIR\LINKDATA.IDX -Algorithm SHA256
Get-FileHash .\USRDIR\LINKDATA.BIN -Algorithm SHA256
Get-FileHash .\PARAM.SFO -Algorithm SHA256
Get-FileHash .\ICON0.PNG -Algorithm SHA256
```

ISO 전체에 `Get-FileHash`를 실행한 값은 위의 내부 파일 해시와 다릅니다. ISO 내부 논리 파일은 여러 extent에 나뉠 수 있으므로 파일을 올바르게 추출하거나 패처의 전체 해시 검증 로그로 확인해야 합니다.

해시 일치는 바이너리 동일성 확인이지 모든 게임 화면의 번역 품질·레이아웃 보증은 아닙니다. [검증 범위](validation.md)를 함께 확인하세요.
