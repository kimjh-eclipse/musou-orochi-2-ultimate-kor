## 빠른 설치

RPCS3 를 완전히 종료한 뒤 `WO3U_ISO_QuickPatch.exe` 를 실행합니다.

- **복호화 ISO**: ISO 를 선택 → **ISO 상태 검사** → 주의사항 동의 → **ISO 에 한국어 패치 적용**
- **폴더형 게임**: RPCS3 루트나 게임 폴더를 선택 → **폴더 게임 상태 검사** → **폴더 게임에 직접 패치**

ISO 는 전체를 복사하지 않고 달라지는 구간만 제자리에 기록하므로 몇 십 초면 끝나고 크기도 바뀌지 않습니다.
쓰기 전 원본 구간을 `.wo3u-backup` 파일에 저장하며, 이 파일로 원본 복구와 다음 버전 갱신을 합니다.
자세한 절차는 [설치 안내](install.md)를 참고하세요.

## 이 프로젝트에서 얻은 것

**모든 수정을 아카이브 슬롯 안에서 끝내면, 20 GB ISO 패치가 36 MB 짜리 제자리 기록으로 줄어듭니다.**

`LINKDATA.BIN`(9.26 GB)의 각 엔트리는 다음 엔트리까지의 고정 슬롯을 갖습니다. 재압축한 데이터가 슬롯을 넘지 않게 하고
색인의 오프셋을 건드리지 않으면 세 파일(`EBOOT.BIN`, `LINKDATA.IDX`, `LINKDATA.BIN`)의 크기가 원본과 같게 유지됩니다.
그러면 ISO9660/UDF 파일 시스템 메타데이터를 손댈 필요가 없고, 원본과 완성본을 바이트 비교한 차이 구간만
ISO 안의 해당 위치에 덮어쓰면 됩니다.

| 항목 | 값 |
|---|---:|
| 차이 구간 | 3,066개 |
| 기록 바이트 | 35,806,779 |
| 그중 EBOOT.BIN | 14,163,546 (디버그 SELF 재포장으로 거의 전체) |
| LINKDATA.BIN | 21,642,123 / 9,259,816,960 (0.23%) |

자세한 설계는 [빠른 패처](patcher.md)에 정리했습니다.

## 법적 고지

이 문서와 저장소는 **원본 게임에서 추출한 텍스트·이미지·폰트·번역 대역 데이터를 포함하지 않습니다.**
패처에 든 것은 원본과 완성본의 차이 바이트뿐이며, 적용에는 본인이 합법적으로 소유한 원본 게임 데이터가 필요합니다.
문서 내 바이너리 오프셋과 구조 명세는 상호운용을 위한 사실 정보입니다.

『無双OROCHI2 Ultimate』 및 관련 상표·저작물의 권리는 코에이 테크모 게임스에 있습니다.
이 프로젝트는 비공식 팬 번역이며 권리자와 아무 관련이 없습니다.
