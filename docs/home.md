# 무쌍 오로치 2 얼티메이트 한국어 패치

PS3 일본판 `BLJM61084`용 비공식 한국어 패치의 사용·기술 문서입니다. 문서 기준 릴리즈는 **v20261010 (2026-10-10)**입니다.

[최신 배포물 받기](https://github.com/kimjh-eclipse/musou-orochi-2-ultimate-kor/releases/tag/v20261010) · [GitHub 저장소](https://github.com/kimjh-eclipse/musou-orochi-2-ultimate-kor)

## 이번 릴리즈

카페 제보를 반영한 번역 수정판입니다.

- 남아 있던 일본어 문장 6,851건을 번역했습니다.
- 전투 메시지 창(40자)을 넘어 잘리던 대사 5,694줄의 길이를 줄였습니다.
- 진형 설명을 두 줄 안에 들어가도록 다시 줄바꿈했습니다.
- 무장·지명 표기를 정리했습니다(코마키, 겐신, 호죠, 큐슈, 쿄토 등).
- 실행 파일 안에 남아 있던 고정 문구 19곳을 번역했습니다.
- 게임 업데이트 1.06 사용자를 위한 업데이트 패처 `WO3U_Update106_KR_Patch.exe`를 추가했습니다.

본편 패처는 이전과 같이 **5파일**(EBOOT·IDX·BIN·SFO·ICON0)을 처리하며 ISO와 폴더형 게임을 모두 지원합니다. 업데이트 패처는 `dev_hdd0/game/BLJM61084`의 업데이트 실행 파일 하나만 고칩니다. 자세한 내용은 [변경 이력](changelog.md)을 참고하세요.

> 다운로드는 Releases의 최신 ZIP을 사용하세요. `tools/`는 이전 3파일 구현의 참고 소스로 보존하며 최신 배포물과 동일하지 않습니다.

## 처음 사용한다면

1. [설치·갱신·복구](install.md)에서 ISO/폴더 중 실제 실행 방식에 맞는 안내를 따릅니다.
2. [해시 목록](hashes.md)으로 배포물과 적용 결과를 확인합니다.
3. [알려진 문제](known-issues.md)에서 미점검 항목과 제보 방법을 확인합니다.

업데이트 1.06을 설치했다면 [업데이트 패처 안내](install.md)도 확인하세요. 원본 게임은 직접 준비해야 하며, 게임 원본·ISO는 제공하지 않습니다. 세이브 삭제나 게임 재등록은 필수 절차가 아닙니다.

## 기술 문서 읽는 순서

```text
IDX/BIN에서 리소스 추출 → 압축 해제 → LX 텍스트 / G1T 이미지 분류
                                      ↓
                          번역·글리프·텍스처 수정
                                      ↓
                  고정 길이 재구성 → 슬롯 용량 검사
                                      ↓
                 차이 구간 팩 → ISO/폴더 적용 → 해시·화면 검증
```

- [아카이브·압축·문자열](formats.md): 데이터가 어디에 있고 어떻게 연결되는지.
- [한글 인코딩·폰트](font-text.md): 한글이 CP932 기반 엔진에서 표시되는 방식.
- [메뉴 이미지 처리](images.md): 텍스트 번역만으로 해결되지 않는 메뉴.
- [실행 파일·제목·아이콘](metadata.md): 아카이브 바깥에 있는 문자열과 메타데이터.
- [패처·ISO·백업](patcher.md): 안전한 배포·갱신·복구의 구현.
- [빌드·검증·조사 범위](validation.md): 완료 판정의 기준과 재현 가능한 범위.
