# 무쌍 오로치 2 얼티메이트 한국어 패치

PS3 일본판 `BLJM61084`용 비공식 한국어 패치의 사용·기술 문서입니다. 문서 기준 릴리즈는 **v20260910b (2026-09-10)**, 문서 갱신일은 **2026-09-19**입니다.

[최신 배포물 받기](https://github.com/kimjh-eclipse/musou-orochi-2-ultimate-kor/releases/tag/v20260910b) · [GitHub 저장소](https://github.com/kimjh-eclipse/musou-orochi-2-ultimate-kor)

## 이번 릴리즈

기존 v20260906b의 번역 데이터 3개 파일은 그대로 유지하고, `PARAM.SFO`의 게임 제목과 `ICON0.PNG`의 목록 아이콘을 한국어로 바꿨습니다. 따라서 최신 패처는 **5파일**을 처리합니다. 게임 크기를 유지하며 ISO와 폴더형 게임 모두 지원합니다.

RPCS3 설정을 바꾸는 임시 표시 변경이 아닙니다. 다만 RPCS3에 별도의 사용자 지정 제목이 있으면 게임의 기본 제목보다 우선할 수 있습니다. 실제 등록된 게임 경로에 패치했는지도 확인해야 합니다.

> 다운로드는 Releases의 ZIP을 사용하세요. 저장소 루트 EXE와 `tools/`는 이전 3파일 구현입니다. 최신 릴리즈와 동일하다고 간주하면 안 됩니다.

## 처음 사용한다면

1. [설치·갱신·복구](install.md)에서 ISO/폴더 중 실제 실행 방식에 맞는 안내를 따릅니다.
2. [해시 목록](hashes.md)으로 배포물과 적용 결과를 확인합니다.
3. [알려진 문제](known-issues.md)에서 미점검 항목과 제보 방법을 확인합니다.

원본 게임은 직접 준비해야 하며, 게임 원본·ISO는 제공하지 않습니다. 세이브 삭제나 게임 재등록은 필수 절차가 아닙니다.

## 기술 문서 읽는 순서

```text
IDX/BIN에서 리소스 추출 → 압축 해제 → LX 텍스트 / G1T 이미지 분류
                                      ↓
                          번역·글리프·텍스처 수정
                                      ↓
                  고정 길이 재구성 → 슬롯 용량 검사
                                      ↓
                 차이 구간 팩 → ISO/폴더 적용 → 해시·화면 검증
```

- [아카이브·압축·문자열](formats.md): 데이터가 어디에 있고 어떻게 연결되는지.
- [한글 인코딩·폰트](font-text.md): 한글이 CP932 기반 엔진에서 표시되는 방식.
- [메뉴 이미지 처리](images.md): 텍스트 번역만으로 해결되지 않는 메뉴.
- [실행 파일·제목·아이콘](metadata.md): 아카이브 바깥에 있는 문자열과 메타데이터.
- [패처·ISO·백업](patcher.md): 안전한 배포·갱신·복구의 구현.
- [빌드·검증·조사 범위](validation.md): 완료 판정의 기준과 재현 가능한 범위.
