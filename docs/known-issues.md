# 알려진 문제

기준: v20260910b / 문서 갱신 2026-09-19. 정식 릴리즈라는 구분은 모든 화면의 완역·검증을 뜻하지 않습니다.

## 이미지·표시 확인이 남은 항목

- 편집 화면의 톱니바퀴 표식과 배경에 겹친 글자 계열: 장착 상태, 공격·방어·이동, 전장, 세력·능력 등. 배경을 보존하는 교체가 필요합니다.
- 아직 분류·점검하지 않은 텍스처의 일본어.
- 긴 이름·문장의 선택 확대 시 잘림, 줄넘침, 작은 이미지의 가독성.
- 무장·병종 이름의 별표·특수문자 수정 후 모든 전투·대화 화면의 표시.
- 최신 SFO 제목·ICON0의 실제 RPCS3 목록·창 표시 재확인. 설치 ISO의 바이트·해시는 확인했습니다.

## 기능·플랫폼 범위

- 실기 CFW PS3 미검증. RPCS3 실행 이력을 실기 호환성 보증으로 해석하지 마세요.
- 음성은 일본어이며 영상·음성을 교체하지 않습니다.
- 키보드 분류 버튼 번역은 한글 입력기 구현이 아닙니다. 문자 그리드는 일본어입니다.
- 검 제작 버튼의 동작 문제는 번역 패치의 수정 범위에서 제외했습니다.
- Steam/PC판에 현재 패처를 적용할 수 없습니다.

## 적용했는데 달라지지 않을 때

1. 릴리즈 ZIP의 패처 버전이 v20260910b인지 확인합니다. 저장소 루트 EXE는 이전 판입니다.
2. 패치한 경로와 실제 부팅하는 ISO/폴더가 같은지 확인합니다.
3. 상태 검사 로그와 적용 직후 5파일 전체 검증 결과를 확인합니다. 빠른 상태 검사만으로 전체 무결성을 판단하지 않습니다.
4. RPCS3를 새로 시작하고 게임 내부 세이브를 불러옵니다. 패치 전 Save State는 사용하지 않습니다.
5. 제목만 다르면 사용자 지정 제목 여부를 확인합니다. 목록 아이콘과 인게임 타이틀 이미지는 별개입니다.

세이브 삭제나 무조건적인 캐시·게임 삭제를 요구하지 않습니다. 원본 복구가 필요하면 해당 대상의 `.wo3u-backup`을 사용하세요. [복구 안내](install.md)를 참고하세요.

## 제보에 필요한 정보

[Issues](https://github.com/kimjh-eclipse/musou-orochi-2-ultimate-kor/issues)에 버전, RPCS3 버전, 대상 방식, 화면 진입 경로, 캡처, 상태 검사 로그를 남겨 주세요. 이미지 누락은 작은 표시·선택 확대를 함께, 이름 문제는 머리 위·대화창을 각각 보여 주면 원인 분류에 도움이 됩니다.

개인 경로·계정 정보는 가리고 원본 게임·ISO·개인 세이브는 첨부하지 마세요.
