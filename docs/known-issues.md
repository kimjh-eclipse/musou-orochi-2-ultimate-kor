# 알려진 문제

작업 진행 중인 패치입니다. 아래는 현재 버전(v20260906b)에서 확인된 상태입니다.

## 1. 아직 확인하지 않은 것

- **실기(CFW PS3).** 확인하지 않았습니다. 디버그 SELF 실행이 필요합니다.
- 최근 버전에서 바꾼 긴 이름·긴 문장의 **실제 화면 표시**(선택 시 확대 잘림, 줄넘침). 파일 검증은 끝났지만 화면 확인이 남았습니다.
- 무장·병종 이름의 특수문자(별표·기호) 처리 뒤 **전투 화면의 실제 표시**.

## 2. 이미지에 남은 원문

- 편집 화면의 톱니바퀴 표식 계열(장착 완료/장착 불가/공격/방어/이동/전장/아군·적·제3세력/능력/플레이어 등).
  배경과 글자가 겹쳐 있어 배경을 보존하는 교체 방식이 필요합니다.
- 아직 점검하지 않은 텍스처가 더 있을 수 있습니다.

## 3. 범위 밖

- 검 제작(무기 제작) 버튼 관련 동작 문제는 이 패치의 범위가 아닙니다.
- 음성은 일본어 그대로입니다.

## 4. 주의사항

- **Save State 로 이어하지 마세요.** 저장 상태는 패치 전 폰트·메모리를 되살릴 수 있습니다.
- 백업 파일 `.wo3u-backup` 은 삭제하지 마세요. 원본 복구와 버전 갱신에 필요합니다.
- 이전 버전이 적용된 대상에 새 버전을 적용할 때는 그 버전의 백업 파일을 함께 지정해야 합니다.
  백업이 없으면 패처는 "원본도 완성본도 아닌 상태"로 보고 쓰지 않습니다.

## 문제가 생겼을 때

1. **상태 검사**(또는 `--verify-only`)로 세 파일 상태를 확인합니다.
2. 원본으로 되돌리려면 **원본 복구**(또는 `--restore`)에 백업 파일을 지정합니다.
3. 게임 폴더를 통째로 지우지 마세요. 백업 복구만으로 충분합니다.

## 세이브 데이터

이 패치는 세이브 데이터 삭제를 요구하지 않습니다. 기존 세이브를 그대로 사용할 수 있습니다.
