# 알려진 문제

기준: v20261010. 정식 릴리즈라는 구분은 모든 화면의 완역·검증을 뜻하지 않습니다.

## 남아 있는 번역·표시 문제

- `錬金宝珠` 표시는 실행 파일과 데이터 어디에도 문자열로 없어 이미지로 보입니다. 아직 일본어입니다.
- 아이템 목록 머리글(`아이템1`과 `장비 아이템 5`)의 모양 차이는 그대로입니다.
- 짧은 전투 메시지 몇 줄은 압축 용량 문제로 이번에 길이를 줄이지 못했습니다. 40자 창에서 잘릴 수 있습니다.
- 편집 화면의 톱니바퀴 표식과 배경에 겹친 글자 계열: 장착 상태, 공격·방어·이동, 전장, 세력·능력 등. 배경을 보존하는 교체가 필요합니다.
- 아직 분류·점검하지 않은 텍스처의 일본어.
- 긴 이름·문장의 선택 확대 시 잘림, 줄넘침, 작은 이미지의 가독성.
- 무장·병종 이름의 별표·특수문자 수정 후 모든 전투·대화 화면의 표시.

## 업데이트 1.06

- 업데이트 1.06을 설치하면 게임은 디스크 실행 파일 대신 `dev_hdd0/game/BLJM61084`의 업데이트 실행 파일을 씁니다. 본편 패처만 적용하면 실행 파일 안의 메뉴 문구와 업데이트가 추가한 문장이 일본어로 남습니다. `WO3U_Update106_KR_Patch.exe`를 함께 적용하세요.
- 업데이트 패처는 실행 파일을 디버그 SELF 형식으로 바꿉니다. 실기(HEN/CFW)에서 실행되는지는 확인하지 못했습니다. 문제가 생기면 같은 패처의 원본 복구로 되돌릴 수 있습니다.
- 업데이트 패처는 업데이트 실행 파일만 고칩니다. 한글 폰트와 대사는 본편 패치에 들어 있으므로 본편 패치를 먼저 적용해야 합니다.

## 기능·플랫폼 범위

- 실기 CFW PS3 미검증. RPCS3 실행 이력을 실기 호환성 보증으로 해석하지 마세요.
- 음성은 일본어이며 영상·음성을 교체하지 않습니다.
- 키보드 분류 버튼 번역은 한글 입력기 구현이 아닙니다. 문자 그리드는 일본어입니다.
- 검 제작 버튼의 동작 문제는 번역 패치의 수정 범위에서 제외했습니다.
- Steam/PC판에 현재 패처를 적용할 수 없습니다.

## 적용했는데 달라지지 않을 때

1. 릴리즈 ZIP의 패처 버전이 v20261010인지 확인합니다. 이전에 내려받은 파일이 남아 있을 수 있습니다.
2. 패치한 경로와 실제 부팅하는 ISO/폴더가 같은지 확인합니다.
3. 업데이트 1.06을 설치했다면 업데이트 패처도 적용했는지 확인합니다.
4. 상태 검사 로그와 적용 직후 전체 검증 결과를 확인합니다. 빠른 상태 검사만으로 전체 무결성을 판단하지 않습니다.
5. RPCS3를 새로 시작하고 게임 내부 세이브를 불러옵니다. 패치 전 Save State는 사용하지 않습니다.
6. 제목만 다르면 사용자 지정 제목 여부를 확인합니다. 목록 아이콘과 인게임 타이틀 이미지는 별개입니다.

세이브 삭제나 무조건적인 캐시·게임 삭제를 요구하지 않습니다. 원본 복구가 필요하면 해당 대상의 `.wo3u-backup`을 사용하세요. [복구 안내](install.md)를 참고하세요.
